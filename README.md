# EcoWise Shopping Assistant

Build a professional and modern responsive website named "Eco-Friendly Shopping Assistant".

Use React.js, Tailwind CSS and JavaScript.

Design requirements:

Green and white eco-friendly theme.

Homepage with navbar, hero section and search bar.

Products page with attractive product cards.

Every product must display name, image, price, category and A-F eco-score.

Color-coded sustainability badges.

Search and filter by category, price and eco-score.

Sticky filter sidebar.

Product comparison for 2 to 5 products in a comparison table.

Wishlist page to save products.

Product details page.

Login and registration pages.

Display "Eco Data Unavailable" for products without sustainability information.

Add at least 15 sample products.

Make all buttons and navigation functional.

Responsive design for mobile, tablet and desktop.

Create a beautiful, clean and professional student project UI.
